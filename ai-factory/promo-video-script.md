### Flowhunt AI Factory: Feature Sheet

**Overview**
Flowhunt AI Factory is a revolutionary AI agent creator that replaces complex visual automation builders with simple natural language. Just describe your goal, and Flowhunt automatically builds, manages, and executes a multi-agent system to get the job done.

**Core Features**

* **Natural Language Task Generation:** Say goodbye to drag-and-drop nodes and manual logic flows. Simply describe your overarching task or project in plain English, and the AI Factory handles the translation into actionable workflows.
* **Smart Integration Suggestions:** Based on your project description, Flowhunt automatically identifies and suggests the required platforms and tools (e.g., GitHub, Slack, Google Search Console, DataForSEO). You just authorize the connections.
* **Automated Multi-Agent Hierarchy:** Once your project is defined, Flowhunt instantly spins up a specialized workforce consisting of:
    * **Supervisor Agent:** The central intelligence overseeing the project and managing user communication.
    * **Leader Agents:** Domain-specific managers (e.g., `newsletter_site_director`).
    * **Worker Agents:** Specialized doers executing specific tasks (e.g., `content_curator`, `growth_analytics_agent`).
* **Intelligent Task Delegation:** Theoverarching project is automatically broken down into discrete tasks, which are intelligently routed and assigned to the most capable worker agents.
* **Real-time Kanban Dashboard:** Track the heartbeat of your AI workforce. Watch as tasks move automatically through stages: *Open, In Progress, Human Input Needed, Done,* and *Failed*. Instantly see which agent is working on what.
* **Context-Aware Supervisor Chat:** Interact directly with your project through a central chat interface. Because the supervisor agent has full context of all agent activities and history, you can:
    * Ask for progress reports (e.g., "What are the latest blogs created?").
    * Request cross-team updates (e.g., "Ask a teammate how SEO is going").
    * Give new instructions or pivot strategies mid-flight.
* **"Human-in-the-Loop" (HITL) Fallback:** Agents are smart enough to know what they don't know. If a task requires an integration setup, an API key, or subjective approval, the task moves to "Human Input Needed," and the agent provides a clear, formatted breakdown of exactly what you need to do to unblock them.
